# v0.1.0

First tagged release of Project Singularity, cut from tag `v0.1.0`
(2026-10-22). With `v1.0.0` tagged later, build the notes below from
the grouped changelog entries up to the 2026-10-21 "live system
constellation" change.

## Highlights

- Eight hand-written modules with zero runtime dependencies: collaborative
  editor (RGA CRDT), in-browser C runtime, WebGL2 engine, X3DH + Double
  Ratchet E2EE, peer mesh, offline storage, accessibility layer, hardening.
- Self-assessed score **708 / 1000** across the eight modules; reviewer's
  independent tally **762 / 1000** (Silver).
- 267 tests across 23 suites, runnable in-browser from the deployed site.
- Cold load **115.3 KiB gzip JS** against a 170 KB budget; deferred graph
  **90.2 KiB** reported separately.
- OWASP ZAP baseline archived (spider + 1,077-request active scan:
  0 High / 0 Medium / 0 Low).
- M1 temporal core adds replayable op-log prefixes with an order-independence
  proof; light theme with `?theme=` override; hash deep links.
